Run gates · 本地验收

15 分钟证明「可治理」；产物目录与截图位供 PR / Release 附证。

  1. 1 · 克隆本仓

    git clone https://github.com/xyan8921/Intdeck-Baseline.git
cd Intdeck-Baseline
npm ci

  2. 2 · Run gates（本仓 CI 等价）

    npm run lint
npm test
npm run redteam:v0

  3. 3 · 证据文件（主仓 Agent CLI 路径）

    # Intdone 主仓：
npm run intdeck:agent -- gates --outDir=out/intdeck-agent-cli
# 人读 evidence.summary.md · 机器 evidence.manifest.json

  4. 4 · 只读回放（可选）

    npm run intdeck:agent -- replay --last=1

写死边界

与 www.intdeck.com 同源；本页展开对照表。

  • 1 · Baseline 永久开源（MIT） 社区在 Intdeck-Baseline 自治演进；发行以 tag 与 Release notes 为准。 Baseline stays open source (MIT) — Community evolves in Intdeck-Baseline; releases are tag + Release notes.
  • 2 · 代码单向断交 不得 merge 回 Intdone；主仓仅 export 投放；禁止批量 cherry-pick 回流。 One-way code boundary — No merge from Baseline into closed Intdone. Export-only tags. No bulk cherry-pick merge-back.
  • 3 · 非实时同源 冻结快照，非 Dev 实时镜像；Console 闭源，无 git 合并。 Not live-synced — Frozen subset snapshot. Console closed-source, not git-merged.
